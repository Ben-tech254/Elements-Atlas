THINK BEFORE YOU PROMPT

Describe the behaviour.
Then ask for the build.

A component name is a starting point. Tell your agent who it serves, what happens, and what a successful result looks like.

  1. 01

    Start with the problem

    “People need to confirm before deleting their project.”

  2. 02

    Name the component & its states

    “Use a confirmation dialog with Cancel and Delete. Disable Delete while saving.”

  3. 03

    Make the result testable

    “Cancel keeps the project. Delete only runs after confirmation. Show an error if it fails.”

✳ Clearer prompts, fewer retries. Token savings depend on your agent and task. Try one small change, check the result, then move on.
